# 建立 Discord Server、頻道，並邀請同學加入

- 適用電腦：Windows 11（你的電腦）
- 要花的時間：約 10 分鐘
- 做完會拿到：一個你自己的 Server、一個給 agent 用的頻道、一個 `CHANNEL_ID`、一條給同學的邀請連結

> **關於畫面名稱：** Discord 會改版，而且你的 Discord 可能是中文或英文介面。下面每個按鈕都寫「中文（English）」。找不到中文，就找括號裡的英文。
> **名詞：**
> - **Server（伺服器）**：Discord 裡一個你自己的「聊天空間」，像一棟大樓。
> - **頻道（Channel）**：Server 裡的一個「聊天室」，像大樓裡的房間。agent 只會聽一個房間。
> - **CHANNEL_ID**：這個房間的編號（一串 17～19 位數字），程式靠它知道要聽哪一間。

---

## 準備

- 一個 Discord 帳號（已登入）。
- 用 **Discord 桌面程式**或瀏覽器打開 <https://discord.com/app> 都可以。下面以桌面程式為例。

---

## 第一部分：建立你自己的 Server

1. 打開 Discord 並登入。
2. 看畫面**最左邊**那一條直的圖示列。
3. 在這一條的**最下面**，點綠色的 **「＋」**（新增伺服器／Add a Server）。
4. 跳出視窗後，點最上面的 **「建立自己的」**（Create My Own）。
5. 它問你這個 Server 是給誰用的，點 **「僅供我和我的朋友使用」**（For me and my friends）。
6. 在「伺服器名稱」欄位輸入名字，例如 `油耗記帳測試`。（大頭貼可以先不管。）
7. 按右下角 **「建立」**（Create）。
8. 你會看到自己進入一個新的 Server，左邊有預設的「一般」（general）頻道。這就成功了。

---

## 第二部分：打開「開發者模式」（為了複製 ID）

不打開這個，後面的右鍵選單裡不會出現「複製頻道 ID」。

1. 看 Discord 視窗**左下角**，你的頭像旁邊有一個**齒輪**，點它（使用者設定／User Settings）。
2. 左邊選單往下找，在「應用程式設定」（App Settings）區塊裡點 **「進階」**（Advanced）。
3. 找到 **「開發者模式」**（Developer Mode），把右邊的開關**打開**（變成綠色）。
4. 按鍵盤左上角的 **Esc** 離開設定。

---

## 第三部分：建立給 agent 用的頻道，並拿到 CHANNEL_ID

### 建立頻道

1. 在你的 Server 裡，看**左邊的頻道清單**。
2. 找到「文字頻道」（Text Channels）這一行，把滑鼠移到它右邊，會出現一個 **「＋」**（建立頻道／Create Channel），點它。
3. 「頻道類型」選 **「文字」**（Text）。
4. 「頻道名稱」輸入 `gas-tracker`（用英文最不會出問題）。
5. **不要**打開「私人頻道」（Private Channel）。
   - 原因：私人頻道要另外把 bot 和同學一個一個加進去，很容易漏。你的 Server 只有你邀請的人進得來，已經夠安全。
6. 按右下角 **「建立頻道」**（Create Channel）。

### 複製 CHANNEL_ID

1. 在左邊頻道清單找到 `gas-tracker`。
2. 在它上面按**滑鼠右鍵**。
3. 在跳出的選單最下面點 **「複製頻道 ID」**（Copy Channel ID）。
   - 看不到這一項？代表第二部分的「開發者模式」沒打開，回去打開。
4. 打開 Windows 的**記事本**，按 `Ctrl + V` 貼上。你會看到一串 17～19 位的數字，例如 `123456789012345678`。
5. 先把這個記事本放著（不用存檔也行），之後要填進 `.env` 的 `CHANNEL_ID=`。
   - 頻道 ID 不是密碼，貼給別人也不會被入侵，但沒有必要就別亂貼。

---

## 第四部分：產生邀請連結，讓同組同學加入

### 先決定連結的規則（比較安全）

| 設定 | 建議 |
|---|---|
| 到期時間 | 7 天（測完就失效） |
| 使用次數上限 | 同學人數，例如 5 |
| 暫時成員資格 | 關閉 |

### 產生連結

1. 在左邊頻道清單，把滑鼠移到 `gas-tracker` 上，右邊會出現一個「**小人加號**」圖示（邀請／Invite），點它。
   - 找不到的話：點視窗**左上角你的 Server 名稱**，在跳出的選單點 **「邀請其他人」**（Invite People）。
2. 跳出的視窗最下方有一行小字 **「編輯邀請連結」**（Edit invite link，旁邊有齒輪圖示），點它。
3. 「邀請到期時間」（Expire After）選 **7 天**（7 days）。
4. 「使用次數上限」（Max Number of Uses）選你要的人數（例如 5）。
5. 確認 **「授予暫時成員資格」**（Grant temporary membership）是**關閉**的。
6. 按 **「產生新連結」**（Generate a New Link）。
7. 按 **「複製」**（Copy）。
8. 把這條連結傳給同學（用 LINE、Messenger 等私訊都可以）。

### 同學要做的事（請他們照做）

1. 點開你給的連結 → 按 **「接受邀請」**（Accept Invite）。
2. **打開私訊權限**（很重要）：agent 會把詳細結果私訊給他們，沒開就收不到，那一筆紀錄也不會被存下來。
   1. 在左邊圖示列點你的 Server（`油耗記帳測試`）。
   2. 點左上角 Server 名稱 → 在選單點 **「隱私設定」**（Privacy Settings）。
   3. 把 **「允許來自伺服器成員的私人訊息」**（Direct Messages）打開。
3. 在 `gas-tracker` 頻道看得到訊息欄就代表加入成功。

> **提醒你自己：** 同學在 `gas-tracker` 傳的每一張照片，都會用掉**你的** Claude 額度（agent 用你電腦上登入的 Claude 帳號）。所以：只邀請你信任的人、不要把連結貼到公開的地方。詳細說明在 `docs/architecture0.md` 第 13 節。

---

## 之後想收回邀請或移除某人

- **關掉邀請連結：** 左上角 Server 名稱 → **「伺服器設定」**（Server Settings）→ 左邊選單 **「邀請」**（Invites）→ 在那條連結右邊按 **X** 刪除。
- **移除某位成員：** 在右邊成員清單對那個人按右鍵 → **「踢出」**（Kick）。
